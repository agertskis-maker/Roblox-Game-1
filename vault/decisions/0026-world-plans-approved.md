## Lead's choices (all reversible)
1. **Summit has no P1/P2/P3 tags.** Its inventory table has no priority column; its 8.4 lists build phases P0 to P7. Reading used: everything in Adam's approved answers is required and built in phase order P1 to P6 (P7 is verification); the plan's "Optional" lines are the conditional P3 tier, built only inside the ceilings. Dusty keeps the inventory tags P1, P2 and P3 as written; its 8.4 phases give the order.
2. **Summit visible-triangle ceiling.** The plan sets none ("log the baseline first"). Used: measure the baseline, then test against 60,000 visible triangles, the figure the Downtown plan proposed and the Dusty plan cites; unique triangles stay at or below the B2 kit's 56,751 as the plan says. Labelled as the lead's number in every table.
3. **New kit folder.** The new World meshes go to `Car-Hop-Art\downtown-kit-worlds-v2\` (mesh JSON for the EditableMesh preview, OBJ for the upload). The old `downtown-kit-worlds\` stays untouched so the "before" views stay reproducible and the HUD playground backdrop does not change.
4. **Memory floor.** The brief says to pause heavy work under 4 GB free; Adam told the Speedway session on 2026-10-28 to keep going and just report it. This task follows his later words: report dips, do not stop, and do not run Blender next to Studio when memory is very low.
5. **Folders changed.** `src/lookdev/Downtown/**`, `assets/downtown/kit/**`, `playground/downtown.project.json` only if needed, `vault/**`. `AGENTS.md` does not list `src/lookdev` or `assets/downtown` in its lane table; the plans and the City README call them Lane 3 look-dev, and neither is in Brian R's or Brian L's paths.
