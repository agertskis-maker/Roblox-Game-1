### Steps for Brian R and Brian L (your own machine, your own private test place)
1. Pull `main`, then run `rokit install` (Rojo 7.7.1), `rojo plugin install`, and restart Studio.
2. Register the Studio MCP server for your user: `claude mcp add --scope user Roblox_Studio -- cmd.exe /c %LOCALAPPDATA%\Roblox\mcp.bat`. In Studio, turn on the built-in MCP server once (Assistant panel, the "..." menu, Manage MCP Servers, "Enable Studio as MCP server"; these labels come from Adam's brief and were not re-checked on this PC because it was already on).
3. Ask Adam for approval before publishing anything ([[0006-studio-mcp-rules]]). Then, in your own test place:
   1. File, then "Save to Roblox As", then "Create new experience…".
   2. Name it plainly and leave the description empty; check Creator is "Me".
   3. Turn Team Create off; turn Data Sharing off (recommended).
   4. Click Save, then Close.
   5. Read your place and universe IDs. In the command bar, `print(game.PlaceId, game.GameId)` is read-only.
4. Make your own project file **outside the repository**, never in `default.project.json`. Either copy the shape of `default.project.json` with `../Roblox-Game-1/` paths, as Adam's stopgap does, or wrap it: `{ "name": "<your project name>", "servePort": 34872, "servePlaceIds": [<your placeId>], "tree": { "$path": "<path to>/default.project.json" } }`. The wrapper form is supported by the Rojo 7.7.1 source but has not been tested yet.
5. In Studio, open the Rojo panel and click Settings: turn on Auto Reconnect, keep Sync Reminder Polling on, and set Confirmation Behavior to "Unlisted PlaceId". Or edit `settings.json` as above with every Studio closed, after a backup.
6. Run `rojo serve <your project file>`, open your published place, and press Connect once. From then on, start `rojo serve` and open the place with `RobloxStudioBeta.exe -task EditPlace -placeId <placeId> -universeId <universeId>`; Rojo reconnects by itself.
